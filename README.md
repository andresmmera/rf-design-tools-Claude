# RF Design Tools

Browser-based calculators and viewers for radio-frequency design. Each tool is a single HTML page that runs locally in your browser, with no installation or server needed.

**Live site:** https://andresmmera.github.io/rf-design-tools-Claude/

## Tools

| Tool | Description |
| --- | --- |
| [Impedance Matching](Impedance%20Matching.html) | Design matching networks between a source and a load impedance. |
| [S-parameter Viewer](S-parameter%20Viewer.html) | Load and plot S-parameter data from network measurements. |

## Using the tools

**Online:** Open the live site above and pick a tool from the main page.

**Offline:** Clone or download this repository and open `index.html` (or any tool file) in a web browser.

```bash
git clone https://github.com/andresmmera/rf-design-tools-Claude.git
```

## Disclaimer

**These tools were generated with AI.** The code was written by an AI assistant (Claude, by Anthropic). The developer has tested the tools but has not independently verified every calculation or edge case.

Results may contain errors. Check anything that matters against a trusted reference, a simulator, or a measurement before relying on it, especially before using it in a product, a design review, or a purchase decision. The tools are intended for learning and quick estimates and are not a replacement for professional engineering judgement.

## Reporting problems

If you find a bug or a wrong result, please [open an issue](https://github.com/andresmmera/rf-design-tools-Claude/issues).
